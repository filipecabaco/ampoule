# Surface brief: site/index.html

Scope: the GitHub Pages landing site. Visitor mode: Persuade.
Audience: Elixir developers shipping apps. Action: install ampoule and run `ampoule release` on their own project; secondary: the GitHub repo.
Proof: measured numbers from examples/francis, real `ampoule release` output, the FROM scratch container run, Realtime's 53/53 e2e suite, the three examples with e2e suites. Nothing else is claimed.
Constraint pinned by the user: no purple anywhere on the site. The violet logo file stays as it is; the site prints the mark as a one-ink stamp.

## Direction contract
