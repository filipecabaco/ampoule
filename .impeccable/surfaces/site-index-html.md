# Surface brief: site/index.html
Scope: the GitHub Pages landing site. Visitor mode: Persuade.
Audience: Elixir developers shipping apps. Action: install ampoule and run `ampoule release` on their own project; secondary: the GitHub repo.
Proof: measured numbers from examples/francis, real `ampoule release` output, the FROM scratch container run, Realtime's 53/53 e2e suite, the six examples with e2e suites. Nothing else is claimed.
Constraints pinned by the user: colours are WebAssembly blue (#654ff0) and Elixir purple (#4e2a8e) so visitors read it as Elixir plus wasm (this reverses the earlier no-purple rule). No crossed-out list of other tools: nothing that reads as confrontational. The previous "package insert" world was rejected as "meh".
## Direction contract
THESIS: The shortest assembly manual ever printed: one part, two steps. Refuses the dark terminal hero plus feature grid.
OWN-WORLD: White sheet, heavy black technical line drawings, wordless pictogram figures, circled step numerals at impact scale, 3px ink rules between sheets; Elixir purple owns the cover panel, wasm blue marks the one file and every active state.
STORY: The visitor sees one file is all they ship, follows two steps (`ampoule release`, copy the file), then optional fittings grouped by need (running, shipping, reaching the host), rules, an exploded view of the file and the spec sheet.
FIRST VIEWPORT: Left, Elixir-purple cover: name, claim, the one-part card. Right: ① figure at laptop, install and `ampoule release` with copy; ② figure carries the file to a server.
FORM: Two-Step Assembly Sheet, candidate 4 of 7, seed 1fb8b2ff re-roll 1.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
